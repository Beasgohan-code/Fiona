FIONA DEPLOYMENT
================

Unified deployment: one Compose service runs the music and character-collection
features together. Do not deploy music/ and waifu/ as separate bots.

REQUIREMENTS
------------
- Docker Engine with the Compose plugin
- A Telegram bot token, API_ID, API_HASH, and numeric OWNER_ID
- MongoDB URI reachable from the container
- At least one assistant STRING_SESSIONS value for voice-chat playback

FIRST START
-----------
1. Copy .env.example to .env.
2. Fill in API_ID, API_HASH, BOT_TOKEN, MONGO_DB_URI, OWNER_ID, and
   STRING_SESSIONS. Optional links and API integrations can remain blank.
3. Keep .env private; it is excluded from the image build context.
4. From this directory, run:

   docker compose up --build -d
   docker compose logs -f fiona

STOP / UPDATE
-------------
- Stop:  docker compose down
- Update: docker compose up --build -d

RENDER
------
A Render Blueprint is included in render.yaml. Create a Blueprint from this
repository, then provide the required Telegram, MongoDB, owner, and assistant
session environment variables in Render. The Docker process exposes /health on
the Render-provided PORT. Choose an always-on paid web instance for continuous
bot availability: a free Render web instance can sleep, and an HTTP health
endpoint or self-ping script cannot guarantee that it stays awake.

YOUTUBE COOKIES (OPTIONAL)
--------------------------
The bot can use YouTube cookies to access videos that require a signed-in
session. Export your own cookies in Netscape cookies.txt format. Never commit,
share, or paste this file into chat; it is equivalent to a login credential.

On Render, open the service's Environment settings and add a Secret File named
"youtube-cookies.txt". Render mounts it at /etc/secrets/youtube-cookies.txt;
keep YT_COOKIES set to that exact path (the supplied render.yaml already does).
Redeploy after adding or replacing the secret file. Cookie files can expire and
may need re-exporting. Cookies are optional; leave YT_COOKIES empty if you do
not need authenticated YouTube playback.

The container runs as the non-root fiona user. MongoDB holds bot data; local
cache/download files are container-local and may be discarded on replacement.
The image has not been built in this environment; validate it on a Docker host
before relying on it in production.
